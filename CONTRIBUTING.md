# Участие в проекте / Contributing

## Русский

Спасибо за интерес к EGO. До первой версии проект ведёт один владелец. Этот файл описывает, как будут приниматься изменения, когда проект откроется.

- Прочитайте [README](README.md), [архитектуру](docs/ru/ARCHITECTURE.md) и [руководство разработчика](docs/ru/DEVELOPER_GUIDE.md).
- Для крупного изменения сначала откройте issue, чтобы согласовать подход. Планы — в [дорожной карте](docs/ru/ROADMAP.md).
- Изменения должны быть обратно совместимыми: поля API добавляются, но не удаляются.
- Не коммитьте личные данные, пароли, токены, настройки почты, пути с вашего компьютера и текст историй. Логи не должны содержать текст историй.
- Каждый новый код ошибки добавляется в каталог ошибок с текстом на русском и английском.
- Перед pull request запустите тесты и обновите снимок контракта API, если меняли API.
- Сообщения коммитов — в повелительном наклонении, одна строка для сути.

Порядок: создайте ветку от `main`, внесите изменение с тестами, запустите тесты, откройте pull request по шаблону.

Вклад распространяется на тех же условиях, что и проект: PolyForm Noncommercial 1.0.0 (файл LICENSE).

## English

Thank you for your interest in EGO. Until the first release, one owner runs the project. This file describes how changes will be accepted once the project opens up.

- Read the [README](README.md), the [architecture](docs/en/ARCHITECTURE.md) and the [developer guide](docs/en/DEVELOPER_GUIDE.md).
- For a large change, open an issue first to agree on the approach. Plans are in the [roadmap](docs/en/ROADMAP.md).
- Changes must be backward compatible: API fields are added, not removed.
- Do not commit personal data, passwords, tokens, mail settings, paths from your machine or story text. Logs must not contain story text.
- Every new error code goes into the error catalog with text in Russian and English.
- Before a pull request, run the tests and update the API contract snapshot if you changed the API.
- Write commit messages in the imperative mood, with a one-line summary.

Process: create a branch from `main`, make the change with tests, run the tests, and open a pull request using the template.

Contributions are covered by the same terms as the project: PolyForm Noncommercial 1.0.0 (see LICENSE).
