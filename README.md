## Русский

Локальный сервис для длинных ролевых историй с языковой моделью. Модель работает на вашем компьютере, данные хранятся зашифрованными. Все действия в историях вымышленные; жёсткие запреты (несовершеннолетние, реальные люди, сексуальное без согласия) действуют всегда.

**Статус:** проект в разработке, репозиторий приватный. Код приложения будет загружен после выпуска первой некоммерческой версии. Сейчас здесь документация.

## English

A local service for long roleplay stories with a language model. The model runs on your own computer, and your data is stored encrypted. All actions in stories are fictional; hard limits (minors, real people, non-consensual sexual content) always apply.

**Status:** in development, private repository. The application code will be uploaded after the first non-commercial release. For now the repository contains documentation.
