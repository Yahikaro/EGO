# EGO

Локальный сервис для длинных ролевых историй с языковой моделью. Модель работает на твоём компьютере, данные хранятся зашифрованными. Все действия в историях вымышленные; жёсткие запреты (несовершеннолетние, реальные люди, сексуальное без согласия) действуют всегда.

**Статус:** проект в разработке, приватный. Код будет загружен в репозиторий после выпуска первой некоммерческой версии. Сейчас здесь документация.
