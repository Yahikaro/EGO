# EGO

Локальный сервис для длинных ролевых историй с языковой моделью. Модель работает на твоём компьютере, данные хранятся зашифрованными.

## Статус

Проект в разработке. Код будет загружен в этот репозиторий после выпуска первой некоммерческой версии.

## Планируемая структура

- `server/` — ядро сервиса (API, модель, память, аккаунты)
- `client/` — веб-клиент, открывается через ядро
- `tests/` — автотесты
- `docs/` — документация
- `packaging/` — сборка исполняемых файлов

## Лицензия

Не выбрана. Будет добавлена вместе с первой версией.
