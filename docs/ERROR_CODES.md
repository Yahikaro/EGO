# Коды ошибок EGO

Генерируется из `server/ego_core/errors.py` скриптом `scripts/export_error_codes.py`.
Код — стабильный машинный контракт API; тексты можно менять. Ответ API об ошибке:
`{"code": "...", "message": "...", "hint": "..."}`. Полный каталог отдаёт `GET /v1/errors`.

| Код | Что случилось | Что делать |
|---|---|---|
| `ACCOUNTS_UNAVAILABLE` | Вход по аккаунту сейчас недоступен. | Перезапустите EGO Core. |
| `ACCOUNT_EXISTS` | Аккаунт на этой установке уже создан. | Войдите с его почтой и паролем. Один аккаунт на установку. |
| `ACCOUNT_INVALID_CREDENTIALS` | Неверная почта или пароль. | Проверьте раскладку и Caps Lock. Забыли пароль — нажмите «Забыли пароль?». |
| `ACCOUNT_INVALID_EMAIL` | Неверный адрес почты. | Проверьте адрес, например name@example.com. |
| `ACCOUNT_LOCKED` | Вход временно заблокирован из-за неверных попыток. | Подождите: после неверных кодов — 15 минут, после неверных паролей — 1 час. |
| `ACCOUNT_RATE_LIMITED` | Слишком много попыток входа подряд. | Подождите минуту и попробуйте снова. |
| `ACCOUNT_WEAK_PASSWORD` | Слишком короткий пароль. | Нужно не меньше 10 символов. |
| `API_PORT_IN_USE` | Порт API занят другой программой. | Закройте программу, занявшую порт, или смените «Порт API» в профиле модели. |
| `BROWSER_UNAVAILABLE` | Не удалось открыть браузер. | Откройте ссылку на клиент вручную или повторите. |
| `CHARACTER_REQUIRES_LLAMA` | Персонажи работают только с llama-server. | Выберите профиль с llama-server. |
| `CLIENT_NOT_INSTALLED` | Не найдена папка клиента EGO. | Клиент должен лежать в папке EGO\client (с файлом index.html внутри). |
| `CONFIG_INVALID` | Неверная конфигурация. | Исправьте настройки на вкладке «Запуск»; данные не сбрасываются. |
| `CONTENT_BLOCKED` | Запрос или ответ нарушает жёсткие ограничения EGO и не сохранён. | Измените сцену: несовершеннолетние и сцены без согласия недопустимы. |
| `CONTEXT_BUDGET_EXCEEDED` | Сообщение или профиль персонажа не помещаются в память модели. | Сократите сообщение или профиль, либо выберите пресет «Длинные сцены». |
| `CONTINUATION_REQUIRES_LLAMA` | «Продолжить» работает только с llama-server. | Выберите профиль с llama-server. |
| `CORE_ALREADY_RUNNING` | EGO Core уже запущен. | Ничего делать не нужно. |
| `CORE_AUTH_FAILED` | Сервер не принял ключ доступа этой установки. | Перезапустите Control Center; если не поможет — проверьте, что запущен Core из этой папки. |
| `CORE_BUSY` | Модель занята: идёт генерация или загрузка. | Дождитесь окончания или остановите текущий ответ. |
| `CORE_INSTALLATION_MISMATCH` | На порту отвечает другая установка EGO. | Остановите её из её собственного окна или BAT; чужой процесс принудительно не завершается. |
| `CORE_NETWORK_ERROR` | Соединение с Core прервалось. | Повторите действие; если повторяется — перезапустите Core. |
| `CORE_OFFLINE` | EGO Core не запущен. | Запустите START_EGO_SERVER.bat или EGO.exe и повторите. |
| `CORE_PROCESS_OWNERSHIP_FAILED` | Не удалось закрепить процессы Core за этой установкой. | Перезапустите EGO; данные не затронуты. |
| `CORE_REQUEST_FAILED` | Core отклонил запрос. | Повторите действие; подробности — в диагностике. |
| `CORE_RESPONSE_INVALID` | Core вернул неожиданный ответ. | Перезапустите Core; если повторяется — сохраните диагностику. |
| `CORE_START_CLEANUP_TIMEOUT` | Не удалось вовремя завершить прерванный запуск Core. | Используйте FORCE_CLOSE_EGO.bat и запустите снова. |
| `CORE_START_FAILED` | Core не смог запуститься. | Откройте журнал logs\latest-core-report.json; частые причины — занятый порт или ошибка ключей. |
| `CORE_START_TIMEOUT` | Core не ответил вовремя при запуске. | Повторите запуск; если повторяется — проверьте диагностику. |
| `CORE_STOPPING` | EGO Core останавливается. | Запустите его снова после остановки. |
| `CORE_STOP_TIMEOUT` | Core не остановился вовремя. | Подождите немного; если не помогает — FORCE_CLOSE_EGO.bat. |
| `CORE_STREAM_INTERRUPTED` | Поток ответа прервался. | Клиент продолжит получать ответ через обычные запросы. |
| `CORE_STREAM_REJECTED` | Core отказал в потоковой передаче ответа. | Повторите запрос. |
| `DATABASE_DOMAIN_MISMATCH` | Файлы баз данных перепутаны. | Верните исходные файлы data\. |
| `DATABASE_LOCKED_OR_INVALID` | База данных занята или повреждена. | Закройте другие копии EGO; не удаляйте файлы data\. |
| `DATA_PATH_UNSAFE` | Небезопасный путь к данным (ссылка или ярлык). | Используйте обычную папку data\. |
| `DEVELOPER_TOOLS_REQUIRE_SOURCE` | Эта проверка доступна только при запуске из исходников. | Используйте START_EGO_SERVER.bat вместо EGO.exe. |
| `DPAPI_OPERATION_FAILED` | Windows не смог расшифровать ключи. | Войдите в тот же профиль Windows, где создана установка. |
| `ENCHANT_EMPTY` | Модель не предложила текст. | Попробуйте ещё раз или допишите пару слов в поле. |
| `ENCHANT_UNAVAILABLE` | Помощник «Enchant» недоступен. | Нужна загруженная локальная модель llama.cpp; запустите модель в EGO Core. |
| `GENERATION_BUSY` | В этой истории уже идёт ответ. | Дождитесь его или нажмите «Стоп». |
| `GENERATION_CANCEL_TIMEOUT` | Модель не остановилась вовремя. | Перезапустите Runtime. |
| `GENERATION_FAILED` | Модель вернула ошибку. | Повторите ответ. |
| `GENERATION_REJECTED` | Модель отклонила запрос. | Проверьте размер контекста и повторите. |
| `IDEMPOTENCY_CONFLICT` | Повтор запроса с другими данными. | Обновите страницу и отправьте заново. |
| `INTERNAL_ERROR` | Внутренняя ошибка сервера. | Повторите; если повторяется — сохраните диагностику. |
| `INVALID_DIAGNOSTIC_CODE` | Неверный код диагностики. | Ничего делать не нужно. |
| `INVALID_DPAPI_INPUT` | Повреждённые данные ключей. | Не изменяйте файлы data\. |
| `INVALID_EVENT_CURSOR` | Повреждённая отметка потока ответа. | Обновите страницу. |
| `INVALID_GENERATION_ID` | Неверный идентификатор ответа. | Обновите страницу. |
| `INVALID_GGUF` | Выбранный файл не является моделью GGUF. | Выберите корректный файл .gguf. |
| `INVALID_ID` | Неверный идентификатор. | Обновите страницу. |
| `INVALID_INPUT` | Некорректные данные. | Проверьте введённые значения и ограничения длины. |
| `INVALID_KEY` | Неверный ключ шифрования. | Используйте тот же профиль Windows, в котором создана установка. |
| `INVALID_REQUEST` | Некорректный запрос. | Проверьте введённые данные. |
| `INVALID_STATE_TRANSITION` | Ответ уже завершён. | Обновите историю. |
| `INVALID_STREAM` | Модель прислала повреждённый ответ. | Повторите; если повторяется — обновите llama.cpp. |
| `LAN_NO_ADDRESS` | Не найден адрес компьютера в домашней сети. | Подключите ПК к роутеру (Wi-Fi или кабель) и перезапустите Core. |
| `LAN_PORT_IN_USE` | Порт для доступа из домашней сети занят. | Выберите другой порт в настройках Control Center и перезапустите Core. |
| `LAN_START_FAILED` | Не удалось включить доступ из домашней сети. | Перезапустите Core; подробности — в диагностике. |
| `LOGS_PATH_UNSAFE` | Небезопасный путь к журналам. | Используйте обычную папку logs\. |
| `LOW_DISK_SPACE` | Мало свободного места на диске. | Освободите хотя бы 500 МБ: базе и журналам нужно место для записи. |
| `MEDIA_FAILED` | Генерация изображения не удалась. | Повторите; при повторе смотрите консоль ComfyUI. |
| `MEDIA_REJECTED` | ComfyUI отклонил запрос. | Проверьте модель и LoRA. |
| `MEDIA_TIMEOUT` | Изображение не успело за 10 минут. | Повторите с меньшим числом шагов. |
| `MEDIA_UNAVAILABLE` | ComfyUI не запущен. | Запустите ComfyUI и повторите. |
| `MEMORY_FULL` | В памяти этого чата слишком много записей. | Удалите ненужные факты (лимит — 300 записей). |
| `MEMORY_UNAVAILABLE` | Память чата недоступна. | Нужна загруженная локальная модель llama.cpp; перезапустите Core. |
| `MODEL_NOT_PROVIDED` | Не выбрана модель (GGUF). | Выберите файл модели на вкладке «Запуск» и примените профиль. |
| `NOTHING_TO_CONTINUE` | Продолжить можно только последний ответ. | Выберите последний ответ персонажа. |
| `NOTHING_TO_REGENERATE` | Перегенерировать можно только последний ответ. | Выберите последний ответ персонажа. |
| `NOT_CONTINUATION` | Это не продолжение ответа. | Повторите действие. |
| `NOT_FOUND` | Запись не найдена. | Возможно, её удалили в другом окне. Обновите страницу. |
| `OPERATION_NOT_FOUND` | Операция не найдена. | Повторите действие. |
| `OUTPUT_LIMIT_EXCEEDED` | Ответ достиг предельной длины. | Начните новую сцену или сократите ответ. |
| `RECORD_LIMIT` | Достигнут предел числа записей. | Удалите ненужных персонажей или миры. |
| `REGENERATION_REQUIRES_LLAMA` | Перегенерация работает только с llama-server. | Выберите профиль с llama-server. |
| `REQUEST_TOO_LARGE` | Слишком большой запрос. | Сократите текст или уменьшите изображение. |
| `RUNTIME_BUSY` | Модель обрабатывает другой запрос. | Повторите через несколько секунд. |
| `RUNTIME_EXITED` | Процесс модели завершился. | Перезапустите Runtime; если повторяется — проверьте VRAM, драйвер и файлы модели. |
| `RUNTIME_INCOMPATIBLE_BINARY` | Выбранный файл не похож на llama-server.exe для 64-битного Windows. | Выберите llama-server.exe из сборки llama.cpp для Windows x64. |
| `RUNTIME_INTERNAL_ERROR` | Внутренняя ошибка при работе с моделью. | Перезапустите Runtime; подробности — в диагностике. |
| `RUNTIME_IO_ERROR` | Связь с моделью прервалась. | Повторите ответ; если повторяется — перезапустите Runtime. |
| `RUNTIME_NOT_PROVIDED` | Не выбран llama-server.exe. | Укажите путь к llama-server на вкладке «Запуск». |
| `RUNTIME_NOT_READY` | Модель ещё не готова или не загрузилась. | Дождитесь READY; при ошибке загрузки — «Перезапустить Runtime». |
| `RUNTIME_PORT_IN_USE` | Порт модели занят другой программой. | Модель не загрузится. Закройте программу или смените «Порт Runtime» в профиле. |
| `RUNTIME_START_FAILED` | Не удалось запустить llama-server. | Проверьте путь к llama-server и файл модели. |
| `RUNTIME_UNAVAILABLE` | Модель не отвечает. | Перезапустите Runtime. |
| `SCHEMA_INVALID` | Неизвестная структура базы данных. | Не удаляйте данные; сохраните диагностику. |
| `SCHEMA_TOO_NEW` | База создана более новой версией EGO. | Запустите более новую версию EGO. |
| `SERVER_RESTARTED` | Core перезапустился во время ответа. | Нажмите «Перегенерировать». |
| `SHUTDOWN_INCOMPLETE` | Core остановился не полностью. | Используйте FORCE_CLOSE_EGO.bat. |
| `SMOKE_TIMEOUT_RESULT_UNKNOWN` | Пробная генерация не завершилась вовремя. | Проверьте состояние модели и повторите. |
| `SQLCIPHER_UNAVAILABLE` | Модуль шифрования SQLCipher не установлен. | Запустите START_EGO_SERVER.bat для установки зависимостей. |
| `STARTUP_CANCELLED` | Загрузка модели отменена. | Запустите её снова, когда будете готовы. |
| `STARTUP_TIMEOUT` | Модель грузилась слишком долго. | Увеличьте тайм-аут загрузки или выберите пресет «Экономия VRAM». |
| `START_IN_PROGRESS` | Модель уже загружается. | Дождитесь окончания загрузки. |
| `STOP_CORE_BEFORE_CONFIGURE` | Сначала остановите Core. | Настройку из командной строки можно делать только при остановленном Core. |
| `STORAGE_FAILURE` | Ошибка хранилища. | Повторите; не удаляйте файлы data\. |
| `STORE_CLOSED` | Хранилище закрыто: Core останавливается. | Запустите Core снова. |
| `STREAM_INTERRUPTED` | Модель оборвала ответ. | Нажмите «Перегенерировать» или «Продолжить». |
| `TERMINAL_STATE_IMMUTABLE` | Завершённый ответ нельзя изменить. | Обновите историю. |
| `TOKENIZE_REJECTED` | Модель не смогла посчитать токены. | Используется запасной подсчёт; ничего делать не нужно. |
| `TTS_BAD_SAMPLE` | Образец голоса не подходит. | Нужен WAV 6–30 секунд, одна речь без музыки. |
| `TTS_FAILED` | Не удалось озвучить текст. | Повторите; при повторе смотрите worker.log. |
| `TTS_LANGUAGE` | Этот движок не поддерживает язык текста. | Выберите другой язык или движок. |

| `TTS_NO_MEMORY` | Не хватило видеопамяти для озвучки. | Дождитесь окончания генерации картинки и повторите. |
| `TTS_UNAVAILABLE` | Озвучка не установлена или не запустилась. | Смотрите docs/TTS.md и tts\worker.log. |
| `TTS_VOICE_MISSING` | Голос не найден или не подходит движку. | Выберите другой голос. |
| `TUNNEL_BINARY_MISSING` | Не найдена программа туннеля cloudflared.exe. | Положите официальный cloudflared-windows-amd64.exe в runtime\tunnel\cloudflared.exe. |
| `TUNNEL_START_FAILED` | Туннель не открылся. | Проверьте интернет и попробуйте ещё раз через минуту. Брандмауэр или антивирус может блокировать cloudflared. |
| `TUNNEL_STOPPED` | Туннель закрылся сам. | Связь с Cloudflare прервалась. Включите туннель снова — адрес и слова будут новыми. |
| `TUNNEL_UNAVAILABLE` | Туннель недоступен в этом запуске Core. | Перезапустите EGO Core и попробуйте снова. |
| `UNAUTHORIZED` | Сессия устарела или нет доступа. | Откройте клиент заново через START_EGO_CLIENT.bat. |
| `UNSUPPORTED_RUNTIME_OPTION` | Эта сборка llama.cpp не поддерживает выбранный параметр. | Верните Auto или выберите другую сборку. |
| `VERSION_CONFLICT` | История изменилась в другом окне. | Обновите страницу и повторите. |
| `VRAM_LIKELY_INSUFFICIENT` | Модель с таким контекстом, вероятно, не поместится в видеопамять. | Выберите пресет «Баланс» или «Экономия VRAM», либо уменьшите контекст. |
| `WINDOWS_DPAPI_REQUIRED` | Нужен Windows (DPAPI). | Запускайте EGO в Windows. |
