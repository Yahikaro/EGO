# EGO с ноутбука в домашней сети

По умолчанию EGO доступен только на компьютере, где он запущен. Доступ с ноутбука
включается отдельно и работает только по HTTPS со входом в аккаунт EGO.

## Включение

1. На ПК создайте аккаунт: окно сервера → «Доступ» → «Аккаунты» → почта и пароль → «Добавить». Письма не отправляются; можно добавить несколько аккаунтов, например для друзей.
2. Control Center → «Доступ» → «Домашняя сеть»:
   отметьте «Разрешить вход по HTTPS» и нажмите «Сохранить доступ из сети».
3. Запустите или перезапустите Core. В том же блоке появятся адрес
   (например `https://192.168.1.100:18444/app/`) и отпечаток сертификата.
4. При первом запуске Windows может спросить, разрешить ли Python доступ к сети.
   Разрешите **только для частных сетей**.

## На ноутбуке

1. Откройте адрес из Control Center в браузере. Ноутбук должен быть в той же сети (тот же роутер).
2. Браузер предупредит, что сертификат не подтверждён: это собственный сертификат EGO.
   Откройте сведения о сертификате, сверьте отпечаток SHA-256 с Control Center и продолжите.
   Если отпечаток другой, не продолжайте.
3. Войдите: почта и пароль. Сессия хранится в этом браузере 7 дней с последней активности.

## Что защищено

- Пароль и код по сети идут только по HTTPS. Обычный HTTP на сетевом порту не отвечает.
- Основной API (порт 18443) по-прежнему слушает только этот ПК.
- С другого устройства работает только сессия аккаунта. Коды запуска, ключ Control Center,
  остановка и перезапуск Core, создание аккаунта — только на самом ПК.
- Сертификат выпускается для адресов ПК в домашней сети и обновляется сам,
  если адрес сменился или срок подходит к концу. Ключ хранится зашифрованным.
- Сервер слушает только адреса домашней сети (192.168.x.x, 10.x.x.x, 172.16–31.x.x), не все интерфейсы.

## Если не открывается

- Адрес ПК сменился (роутер выдал другой): посмотрите новый в Control Center после перезапуска Core.
- Windows блокирует входящие подключения: проверьте, что Python разрешён для частной сети.
- В Control Center показана ошибка `LAN_PORT_IN_USE`: выберите другой порт и перезапустите Core.
