# Озвучка (TTS) — локальная

Необязательная функция. Всё работает на вашем ПК, без облака и платных API; тексты и образцы голосов никуда не отправляются.

## Установка
```
py -3.12 scripts\install_tts.py
```
Скрипт создаёт `tts\.venv` рядом с EGO, ставит torch и coqui-tts (несколько ГБ) и скачивает модель XTTS-v2 (~1,9 ГБ) в `tts\models`. После установки перезапустите Core.

## Архитектура
```
клиент (js/app/tts.js) ──HTTP──> Core (server/ego_core/tts.py, /v1/tts/*)
                                   │ очередь, дедупликация, кэш аудио в памяти
                                   └─HTTP 127.0.0.1:18082──> TTS-процесс (server/ego_tts/worker.py, venv tts\.venv)
```
- Core не импортирует torch; TTS-процесс запускается при первом запросе. Модель выгружается через 120 с простоя.
- Нужно ≥ 2,4 ГБ свободной VRAM, иначе озвучка идёт на CPU (медленно). Принудительно: `EGO_TTS_DEVICE=cpu|cuda`.
- Папку и интерпретатор можно задать переменными `EGO_TTS_HOME`, `EGO_TTS_PYTHON`.

## Голоса
Готовых голосов в EGO нет: каждый пользователь добавляет свои.
- Окно «Голоса» → «Свой голос»: загрузите запись (6–30 с, чистая речь, ≥16 кГц, ≤6 МБ). Браузер сам переводит файл в WAV. Нужно подтвердить, что голос ваш или у вас есть право его использовать.
- Голос назначается персонажу в его карточке (`voice`: голос, скорость, язык, эмоция) и синхронизируется с Core.
- Эмоция — отдельный слой (темп и живость), сам голос не меняется.
- Если голоса не добавлены, «Озвучить» сообщит, что голос не выбран.

## Чат
- «Озвучить» под ответом ИИ: генерация → воспроизведение; повторный клик — пауза. «Авто» озвучивает каждый завершённый ответ. Сообщения пользователя не озвучиваются.
- Длинный текст режется по предложениям, слова не рвутся. Один и тот же текст с тем же голосом генерируется один раз (кэш).

## API
`GET /v1/tts/status`, `GET|POST /v1/tts/voices`, `DELETE /v1/tts/voices/{id}`, `GET /v1/tts/voices/{id}/demo`, `POST /v1/tts/speak` (202, задача), `GET /v1/tts/jobs/{id}`, `GET /v1/tts/jobs/{id}/audio`, `POST /v1/tts/unload`. Коды ошибок `TTS_*` — в `docs/ERROR_CODES.md`.

## Диагностика
- Проверка процесса: `curl http://127.0.0.1:18082/health`; журнал — `tts\worker.log`.
- `transformers` 5.x и `torchcodec` ломают импорт при torch 2.5 — скрипт установки ставит совместимые версии.

## Ограничения
- Веса XTTS-v2 (Coqui Public Model License) — только некоммерческое использование; используя модель, вы принимаете её условия.
- Эмоции в XTTS — только темп и живость.
- В групповом чате голос берётся у основного персонажа.
- Холодный старт ~30–40 с.
