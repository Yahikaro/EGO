# Changelog

## 1.0.0 — first public release

- Local roleplay stories with a language model running on your GPU (llama.cpp); an encrypted database on your computer.
- Server window (Control Center) with six tabs: General, Launch, Health, Access, Settings, Dependencies.
- Browser client (works on a PC, laptop and phone), five languages: Russian, English, French, Spanish, German.
- Accounts: the owner adds logins (email + password) in the server window; friends can have their own logins.
- Optional: access on the home network over HTTPS, a Cloudflare tunnel, voice output (XTTS), picture generation through ComfyUI.
- Windows installer (EGO-Setup.exe) that installs the program and, on request, its dependencies.
